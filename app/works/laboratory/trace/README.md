# Trace

Trace combines the existing Foot print snow surface, To step on animation and supplied shoe OBJ, and Sole's 12 product-inspired generated treads.

The StepApp contact callback fires once after the shoe plants. It reports the actual loaded insole width, length, centre offset, heading, and the three projected screen vectors. Trace turns that projection into a canvas transform, so the vector sole texture stays aligned with the animated shoe even when the camera crop or viewport changes. Trace suppresses To step on's own decal and leaves the new impression on a transparent canvas over Foot print's Painted snow surface. The shoe and passing-trouser silhouette render on a transparent WebGL canvas above both.

Each contact randomly selects one of Sole's 12 product studies, avoiding an immediate repeat. The original `SOLE_OUTLINE` clips the generated tread. Within that outline, final black pixels use Foot print Layer 2's default depth/shadow (10 / 0.5); white pixels use Layer 1's (4 / 0.25). The menu can adjust both independently. The traced outline becomes a signed-distance field with the same fine/broad edge irregularity, sloped wall, light-facing normal, and cast-shadow approach used by Foot print's circle/square/triangle impressions. The black/white layer boundary also changes local height, so individual tread marks have relief. All impressions remain until cleared, with a bounded history of 48 prints. Resizing scales retained print positions and basis vectors without regenerating the step.
